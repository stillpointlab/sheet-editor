sheet-editor preview harness

Interactive sheet selection

Document fixtures add emphasis, alignment, Currency, Percent, decimal-place, and Value format controls to the row/column tools. Left/Right and Home/End move within the toolbar; Escape returns to the grid. Enter quick-edits; F2/double-click caret-edits; Alt/Option+Enter inserts a line break. Escape cancels, Enter/Shift+Enter commit and move, and Ctrl/Cmd+Z undoes in navigation. Grid Ctrl/Cmd+C and Ctrl/Cmd+V copy and paste literal TSV; Delete or Backspace clears values.

Formatting smoke test: use Sheet value formatting to exercise all kinds, mixed selections, decimal bounds, incompatible raw text, editing/copying raw values, undo, reload, read-only, narrow panes, and both themes. The source block below should always show the complete current file.
